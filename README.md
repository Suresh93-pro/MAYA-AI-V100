# MAYA AI V100

MAYA AI is a Windows desktop voice assistant with a neural-style HUD, voice interaction, command execution, Windows automation, and an optional local AI brain.

## Core components

- Voice listener and speaker
- Command engine
- Windows launcher
- Local AI brain
- Animated Tkinter HUD
- System telemetry
- Voice/text command input

## Project status

Version: V100
Platform: Windows
Interface: Tkinter
AI: Local/optional Ollama integration
